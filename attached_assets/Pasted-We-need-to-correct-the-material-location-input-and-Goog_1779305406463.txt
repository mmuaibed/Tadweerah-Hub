We need to correct the material location input and Google Maps behavior.

Current requirement:
The location section should have three separate fields:

1) National Address / Location Code
Arabic label:
"العنوان الوطني / كود الموقع"

English label:
"National Address / Location Code"

Purpose:
This field is used for Google Maps search fallback when no direct Google Maps URL is provided.

2) Site Details / Additional Location Instructions
Arabic label:
"تفاصيل الموقع"

English label:
"Site Details"

Purpose:
Operational notes only, such as gate number, loading point, access instructions, contact person, warehouse name, etc.
This field must NOT be used for Google Maps search.

3) Google Maps URL
Arabic label:
"رابط Google Maps"

English label:
"Google Maps URL"

Purpose:
If provided, this is the primary link used to open the location.

Required Google Maps opening logic:
- If google_maps_url exists:
  open google_maps_url
- Else if material_location_address exists:
  open Google Maps search using material_location_address only
- Else if only city exists:
  fallback to Google Maps search using city only
- Never append city to material_location_address
- Never append site details to the Google Maps query

Example:
material_location_address = "FMDD7920"
city = "الدمام"
site_details = "بوابة 3، المستودع الخلفي"

Generated fallback query should be:
https://www.google.com/maps/search/?api=1&query=FMDD7920

Not:
FMDD7920, الدمام
Not:
FMDD7920, الدمام، بوابة 3
