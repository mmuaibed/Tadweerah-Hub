Issue 4 — Transport decision wording and buttons
Current problem:
The buyer sees a pending action for transport method, but the options are confusing. “No transport needed” is misleading because materials usually require transport. The correct meaning is “I do not need Tadweerah to arrange transport.”

Required behavior:
Use transport_responsibility to show a clear decision to the responsible party only.

If transport_responsibility = buyer:
Show to buyer:
Title:
“هل تريد أن تساعدك تدويرة في ترتيب نقل البضاعة؟”

Two clear buttons/cards:
1) “نعم، رتّبوا لي النقل عبر تدويرة”
Helper:
“سنستلم طلبك ونتواصل معك لترتيب النقل.”

2) “لا، سأرتب النقل بنفسي”
Helper:
“سأقوم بتنسيق النقل مباشرة مع الطرف الآخر خارج المنصة.”

If transport_responsibility = seller:
Show the same decision to seller, not buyer.

Non-responsible party should see information only:
- If buyer responsible, seller sees:
“النقل مسؤولية المشتري. بانتظار المشتري لترتيب النقل أو الحضور للاستلام.”
- If seller responsible, buyer sees:
“النقل مسؤولية البائع. بانتظار البائع لترتيب النقل وإرسال البضاعة.”

Avoid the phrase:
“لا أحتاج نقل”
unless there is a true no-transport case.
