## Item 4 — Required Services Gate

Required services are services needed by the listing, not general company eligibility.

Example:

* transport
* safe disposal
* sorting
* storage

Implementation direction:

* Add required services to the listing as capabilities/services selected by the seller.
* If a listing requires a service, only companies that have that capability can submit an offer.
* If that capability has `requires_license = true`, then the company must also have `license_status = approved`.

So the logic is:

1. Listing requires capability/service X
2. Buyer must have capability X
3. If X requires license → buyer must be approved

This should NOT block normal selling or normal buying unless the listing explicitly requires a service.

Safe disposal should follow this model.
