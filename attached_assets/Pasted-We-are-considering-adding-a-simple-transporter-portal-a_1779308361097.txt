We are considering adding a simple transporter portal and transport quotation flow.

Do not implement yet. Assessment only.

Business idea:
Since Tadweerah supports transporter companies, we want transporters to have a dedicated page different from buyer/seller company pages.

The page should show active transport requests that need pricing. Transporters can review request details and submit a shipping quote. Tadweerah Admin/Ops can then compare quotes and choose/follow up with the best option.

Target MVP concept:

1) Transporter-facing page
Arabic label:
"طلبات النقل المتاحة"

English label:
"Available Transport Requests"

Visible only to companies/users with transporter role/capability.

The transporter should see active transport requests with:
- transport request reference
- related deal reference
- material/subcategory
- quantity/weight
- unit
- pickup city / pickup location
- delivery city / delivery location
- material location address / Google Maps link if safe to show
- required number of trucks, if available
- truck type / transport requirements, if available
- expected pickup date, if available
- special notes / site instructions, if available

2) Transport quote submission
Transporter can submit:
- quote amount
- currency SAR
- estimated pickup date
- estimated delivery date
- number of trucks offered
- truck type / capacity
- notes
- validity period if simple

3) Admin comparison
Admin should see quotes per transport request:
- transporter company
- quote amount
- number of trucks
- estimated dates
- notes
- quote status
- ability to compare quotes

Do not implement auto-award now.
Do not implement payment for transport now.
Do not implement transporter rating now.
Do not implement full dispatch workflow now.

4) Admin decision
For MVP, admin can mark one quote as:
- selected / preferred
or
- under review
or simply record status if that already fits current model.

If selecting a quote requires new lifecycle complexity, defer selection and only show quotes for comparison.
