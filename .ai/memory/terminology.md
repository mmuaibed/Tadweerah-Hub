# Terminology Memory

Use consistent language:

- Discovery: evidence-gathering only.
- Active route: reached through browser navigation or a visible UI link/button.
- Code-present only: route or feature exists in code but was not reached in browser.
- Allocation: sustainability distribution of a received material quantity across pathways.
- Draft allocation: editable allocation not finalized.
- Finalized allocation/report: locked or completed sustainability record.
- Correction request: user request to reopen or revise finalized sustainability data.
- Shipment: contract shipment record under a contract.
- Contract: longer-running agreement with materials and shipments.
- Report list: UI listing reports or finalized records.
- Final report: printable or finalized report view.

When uncertain, write `observed`, `not observed`, or `blocked` instead of guessing.
