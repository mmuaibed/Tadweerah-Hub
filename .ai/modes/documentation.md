# Documentation Mode

Goal: turn verified findings into clear project knowledge.

Allowed:
- Create or update explicitly assigned documentation files.
- Summarize evidence from discovery.
- Create checklists, maps, journey logs, and decision records.

Not allowed unless explicitly authorized:
- Application/source code changes.
- Main project document updates outside the assigned scope.
- Commits, pushes, deploys.

Rules:
- Keep documentation concise and operational.
- Separate observed facts from recommendations.
- Preserve uncertainty. Use labels like `observed`, `not observed`, `blocked`, or `code-present only`.
- Include file paths, routes, commands, and screenshot paths where relevant.
- Do not overwrite strategic project docs during discovery closure unless assigned.

For Pre-Phase 3-B, write findings under:
- `docs/pre-phase-3b-visual-journey/`
